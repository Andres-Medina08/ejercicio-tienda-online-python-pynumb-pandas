# EJERCICIO DE TIENDA ONLINE
###### Este es mi primer proyecto de análisis de datos, en el simulé algunos datos de lo que sería una tienda online, datos que juntos al ser analizados, pudieran tomar decisiones de alto valor a la persona dueña de este negocio online. Utilicé Python con sus librerías pandas y numpy para el analisis de los datos y utilicé Power Bi para la creación de un dashboard que me permitiera una explicación visual de los resultados obtenidos.
## OBJETIVOS DEL PROYECTO
###### Este proyecto tiene como objetivo demostrar que soy capaz de facilitar la toma de decisiones estratégicas para una organización con la transformación de datos númericos como por ejemplo en este caso, ventas. Si esta tienda online de verdad existiera, podría resolver preguntas como:
* ¿Cuál es la ciudad en donde más estamos vendiendo?
* ¿A que línea de productos debemos destinarle mas presupuesto en marketing?
* ¿En que fecha del mes deberíamos tener más inventario?
Entre otras.
## TECNOLOGÍAS UTILIZADAS
* Visual Studio Code como editor de código.
* Python como lenguaje de programación con sus librerías pandas y numpy.
* Power Bi para la creación de visuales representativos de los datos.
* Git y GitHub como controlador de versiones
## FUNCIONALIDADES DEL ANALISIS
* Generación de una determinada cantidad de números aleatorios
* Creación de un dataframe completo con los datos creados previamente para simular la base de datos de una tienda online
* Validación de datos para evitar que existan datos que no son correctos.
* Análisis estadísticos como venta mas alta, producto mas vendido, ventas por ciudad, promedios etc.
* Exportación del dataframe en archivo csv para realizar los respectivos gráficos en Power Bi
## DASHBOARD EN POWER BI
### El dashboard realizado en Power Bi con el fin de representar gráficamente los resultados obtenidos en python para facilitar la toma de decisiones a personas ajenas al análisis de datos mediante programación incluye:
* Gráfico para visualizar la comparación de las ventas realizadas por las diferentes categorías de los productos.
* Comparación del porcentaje de ventas hechas en las diferentes ciudades en las que opera esta tienda online
* Visualización de las cantidad de ventas por productos para determinar cual es el producto más vendido y el producto menos vendido.
* Gráfico para visualizar el progreso diario de las ventas que facilita la determinación de cuales son los días en que más ventas se hicieron
* Datos extras como el total de dinero en vetas, el promedio de este e inclusive la cantidad de dinero ingresada en una categoría especifica
